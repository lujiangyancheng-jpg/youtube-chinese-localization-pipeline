# Windows 正式发布验收清单

每一个公开 Windows Release 都应按以下顺序执行。生成的模型、暂存目录和安装包不提交 Git。

1. 在隔离环境运行 `ruff` 与完整 `pytest`。
2. 每个程序版本构建并验证 Standard 单文件安装包。只有前三段模型 ABI 改变、兼容模型资产缺失或模型运行库变更时，才重建 Whisper Small、Whisper Medium、Local AI 与 AI 超分辨率组件包；否则复用同三段版本已发布且哈希已验证的资产。
3. 对 Standard 执行独立安装与原位升级验证，确认基础翻译模型、字体、图标和原生启动器可用，已安装的 Whisper、Local AI 与 AI 超分辨率组件在升级后字节数不变。当模型 ABI 或运行库变更时，还必须执行真实 Whisper 离线加载、本地 Qwen 推理和短视频超分处理。
4. 测试默认安装目录，以及含空格和 Unicode 字符的自定义安装目录。检查开始菜单快捷方式指向 `Localize Studio.exe`，并运行 `Localize Studio.exe --verify`。
5. 如果持有正式代码签名证书：在生成安装包时传入 `-CertificateThumbprint`，构建脚本会在写入 SHA-256 前验证 Authenticode 签名。没有可验证证书时，README 和 Release 说明必须明确标注“未代码签名”与 SmartScreen 提示，并附上 SHA-256；不得声称已签名。
6. 验证至少以下故障路径：缺少模型包、模型包与基础包版本不匹配、CUDA 不可用回退 CPU、首选 Vulkan 设备失败后自动尝试其他设备、编码器不可用回退 CPU、磁盘空间预检失败、取消后 `--resume`、GUI 队列仅重试未完成项目、单任务暂停不影响其他任务、重启后运行中状态变为可继续、普通媒体预分析失败后仍可开始、动态播放页失败会强制分流到浏览器抓取、输入改变取消待续跑请求、过期检查缓存安全失效，以及自动诊断包不包含隐私内容。
7. 验证逐视频任务中心的标题／媒体信息／阶段／进度更新、移除所选和打开项目；关闭并重启后确认常用设置恢复，同时确认设置文件不含 API Key。
8. 上传前检查 Release 说明、更新日志、安装说明和版本号；上传后比较 GitHub 返回的每个资产大小和 SHA-256 摘要。

正式版必须在 GitHub 上作为非 Pre-release 发布，且稳定更新通道能够检测到它。
