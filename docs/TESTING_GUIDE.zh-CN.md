# Video Localizer 15 分钟测试清单

这份清单适合普通用户和测试者。目标不是跑完所有功能，而是用一台真实电脑完成一条可复现工作流，并把电脑配置、输入类型、结果和失败阶段说明清楚。

## 测试前

1. 从 [GitHub Releases](https://github.com/lujiangyancheng-jpg/video-localizer/releases/latest) 下载最新版 Standard 安装包和 `SHA256SUMS.txt`。
2. 在 PowerShell 中运行 `Get-FileHash .\YouTube-Chinese-Localizer-*-Setup.exe -Algorithm SHA256`，确认摘要相同。
3. 记录 Windows 版本、CPU、内存、显卡与显存、显卡驱动版本、可用磁盘空间，以及安装的 Whisper 模型。
4. 只使用你拥有、已获授权、属于公共领域或许可允许本次测试的视频。

当前安装包没有商业代码签名，SmartScreen 可能显示来源提示。不要从网盘、群文件或第三方下载站获取安装包。

## 任选一条主路线

### A. 无字幕下载

- 粘贴一个可公开访问的短视频链接。
- 确认任务卡显示标题、时长、分辨率、帧率与预估大小。
- 选择“仅下载原视频（无字幕）”，完成后检查画面、声音、分辨率和时长。

### B. 本地中英字幕

- 选择一段 2–10 分钟、语音清晰的中文或英文视频。
- 使用 Whisper Small 和“本地快速翻译”。
- 检查识别语言、断句、专有名词、字幕是否遮挡主体，以及最终视频能否完整播放。

### C. 本地 AI 段落翻译

- 使用同一个短视频和 Local AI，比较快速翻译与段落翻译的自然度。
- 安装可选 AI 超分辨率组件，用一段低清短片分别测试“通用实拍”和“动画”；记录实际使用的 Vulkan 设备、耗时、输出分辨率和是否出现人工纹理。
- 检查项目 `publishing` 文件夹中是否生成版权记录与署名文本，并确认缺少许可链接时界面会阻止开始。
- 记录翻译耗时、峰值内存/显存、是否出现电脑明显卡顿，以及有问题的字幕序号。不要公开粘贴受版权保护的完整字幕。

### D. 暂停与恢复

- 在识别、翻译或压制阶段暂停一个任务，关闭并重新打开程序。
- 继续未完成任务，确认已完成阶段没有重复执行，最终视频仍能通过检查。

## 额外观察

- 安装器能否只下载勾选的模型；取消下载后能否正常保留 Standard。
- NVIDIA / Intel / AMD 硬件编码失败时是否自动回退，界面是否给出可理解的原因。
- 4K、高帧率、长视频和低磁盘空间下，预估、进度、速度和剩余时间是否可信。
- 动态公开播放页是否正确引导到隔离 Edge 抓取；抓取窗口不应读取日常浏览器登录状态。
- 失败后“重试未完成任务”是否复用已有下载、字幕和中间结果。

## 如何反馈

创建 [Bug 报告](https://github.com/lujiangyancheng-jpg/video-localizer/issues/new?template=bug_report.yml)，填写：

- 预期发生什么、实际发生什么；
- 最少、按顺序排列的复现步骤；
- 上述硬件和版本信息；
- 失败发生在下载、识别、翻译、字幕检查还是压制；
- 脱敏诊断包，以及必要的截图。

请先搜索已有 Issue，避免重复。不能稳定复现或想先讨论的结果可以发到 [Discussions](https://github.com/lujiangyancheng-jpg/video-localizer/discussions)。不要公开 API Key、Cookie、令牌、私人视频、完整字幕、含查询签名的媒体直链或未经脱敏的日志。
